Linux: X11 vs Wayland

Veyndesk currently supports Linux X11 sessions only. How to check whether you're on Wayland and how to switch to Xorg on Ubuntu, Fedora and others.

Last updated 21 October 2026 · Veyndesk 0.5.0

Veyndesk on Linux currently works only in an X11 (Xorg) session. In a Wayland session the screen can't be captured or controlled this way. Wayland support is planned.

Check which one you use

echo $XDG_SESSION_TYPE

It prints x11 or wayland.

Switch to X11

  • Ubuntu (GNOME): log out, click your name, click the gear icon at the bottom right, choose Ubuntu on Xorg, then log in.
  • Fedora (GNOME): the gear icon on the login screen offers GNOME on Xorg if the X11 session package is installed. Recent Fedora versions may not include it.
  • KDE Plasma: choose Plasma (X11) in the session menu on the login screen, if your distribution still provides it.
  • Linux Mint (Cinnamon), Xfce, MATE: already X11 by default.

Other Linux notes

  • Packages are 64-bit x86 only.
  • If the AppImage doesn't start, make it executable (chmod +x); some systems also need libfuse2.
