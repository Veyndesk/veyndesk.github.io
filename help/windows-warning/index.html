Windows installer warning

Why Windows shows a SmartScreen or Smart App Control warning for the Veyndesk installer, and how to install it safely.

Last updated 21 October 2026 · Veyndesk 0.5.0

The Veyndesk installer is not code-signed yet, so Windows doesn't recognise the publisher and may warn you.

“Windows protected your PC” (SmartScreen)

Click More info, check the file name is Veyndesk_x.y.z_x64-setup.exe, then click Run anyway.

Smart App Control blocked it

Smart App Control (Windows 11) blocks unsigned apps completely and has no “run anyway” button. Options:

  • Wait for a signed release. Free code signing for open-source projects (SignPath Foundation) is planned.
  • Turning Smart App Control off is possible in Windows Security → App & browser control, but on many Windows versions it can't be turned on again without reinstalling Windows. Only do this if you understand that trade-off.

Is the download safe?

  • Download only from the official GitHub release page.
  • Files there are built by GitHub Actions from the public source code, and each has a SHA-256 checksum. In PowerShell: Get-FileHash .\Veyndesk_0.5.0_x64-setup.exe and compare.
