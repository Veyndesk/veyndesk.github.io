About Veyndesk

A free, open-source remote desktop, built in the open.

Last updated 21 October 2026 · Veyndesk 0.5.0

Who makes it

Veyndesk is an independent open-source project maintained on GitHub by KavindaBanukaVC, in the Veyndesk organisation. It is not a company product and has no paid plans. It is written in Rust (the app is built with Tauri).

Project status

  • Latest version: 0.5.0, released 21 October 2026. See the changelog.
  • Stage: early. The core works (connect by ID, accept, control); file transfer, mobile apps, Wayland and code signing are not done yet.
  • What's tested: see the test status table.
  • Licence: GNU AGPL-3.0. Some ideas are inspired by RustDesk (also AGPL-3.0).
