Veyndesk for macOS

Requirements: macOS 10.15 Catalina or later, Apple Silicon or Intel.

Last updated 21 October 2026 · Veyndesk 0.5.0

⬇ Download Veyndesk 0.5.0 for macOS

FileUse it for
Veyndesk_0.5.0_universal.dmgUniversal app for Apple Silicon and Intel Macs.

Install

  1. Download Veyndesk_0.5.0_universal.dmg from the release page, open it and drag Veyndesk to Applications.
  2. The first time, right-click Veyndesk in Applications → Open → Open. (The app isn't notarized by Apple yet, so a normal double-click is blocked.) On newer macOS versions you may instead need System Settings → Privacy & Security → Open Anyway.

Permissions (needed to be controlled)

To let a partner see and control your Mac, allow Veyndesk in System Settings → Privacy & Security:

  • Screen Recording (macOS 15+: Screen & System Audio Recording) so the screen can be shared.
  • Accessibility so the partner's mouse and keyboard work.

Then quit and reopen Veyndesk. Step-by-step: Mac screen permission. You don't need these permissions only to control another computer.

Limitations on macOS

  • Not notarized yet (right-click → Open on first start).
  • Built and packaged automatically, but not yet tested by the maintainer on a physical Mac. Please report problems.

Uninstall

Drag Veyndesk from Applications to the Trash. Settings are in ~/Library/Application Support/Veyndesk.
