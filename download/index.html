Known limitations

  • No file transfer, chat, audio or session recording yet. Clipboard text sync works.
  • No mobile apps (Android/iOS) yet.
  • Linux: X11 sessions only. Wayland is not supported yet.
  • macOS: the app is not notarized yet, and it has not yet been tested by the maintainer on a physical Mac (it is built and packaged automatically).
  • Windows: the installer is not code-signed yet, so Windows shows a warning. There is no background service yet, so the login screen and UAC prompts can't be controlled.
  • Internet connections depend on public services (ntfy.sh for finding the partner, Cloudflare for the relay). A network that blocks them can only use Veyndesk on the local network.
