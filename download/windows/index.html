Veyndesk for Windows

Requirements: Windows 10 or 11, 64-bit (x64).

Last updated 21 October 2026 · Veyndesk 0.5.0

⬇ Download Veyndesk 0.5.0 for Windows

FileUse it for
Veyndesk_0.5.0_x64-setup.exeInstaller (recommended). Adds a firewall rule so direct connections work.
Veyndesk-windows-portable.zipPortable: unzip and run Veyndesk.exe, no install.

Install

  1. Download Veyndesk_0.5.0_x64-setup.exe from the release page.
  2. Run it. Windows may say "Windows protected your PC" because the installer isn't code-signed yet: click More info → Run anyway. If Smart App Control blocks it completely, see Windows installer warning.
  3. Veyndesk starts and shows your ID and password.

Permissions

The installer adds a Windows Firewall rule named "Veyndesk" so other computers can connect directly. The portable version doesn't, so Windows may ask once whether to allow it.

Limitations on Windows

  • Installer not code-signed yet (warning on install).
  • No background service yet: the Windows login screen, lock screen and UAC (admin) prompts can't be seen or controlled remotely.

Uninstall

Settings → Apps → Veyndesk → Uninstall. Your ID and settings stay in %APPDATA%\Veyndesk; delete that folder to remove them too.
