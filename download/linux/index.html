Veyndesk for Linux

Requirements: 64-bit (x86-64) Linux with an X11 session.

Last updated 21 October 2026 · Veyndesk 0.5.0

⬇ Download Veyndesk 0.5.0 for Linux

FileUse it for
Veyndesk_0.5.0_amd64.debFor Ubuntu, Debian, Linux Mint and other Debian-based systems.
Veyndesk_0.5.0_amd64.AppImageFor most other distributions: make it executable and run it.

Install

Ubuntu, Debian, Mint: download Veyndesk_0.5.0_amd64.deb, then:

sudo apt install ./Veyndesk_0.5.0_amd64.deb

Other distributions: download the AppImage, then:

chmod +x Veyndesk_0.5.0_amd64.AppImage
./Veyndesk_0.5.0_amd64.AppImage

X11 session required

Veyndesk can currently share and control the screen only in an X11 session. Many distributions (Ubuntu 22.04+, Fedora) use Wayland by default. On Ubuntu, log out, click the gear icon on the login screen and choose "Ubuntu on Xorg". More: Linux X11 vs Wayland.

Limitations on Linux

  • Wayland not supported yet.
  • 64-bit x86 only (no ARM build yet).

Uninstall

sudo apt remove veyndesk (or delete the AppImage). Settings are in ~/.config/Veyndesk.
