Changelog

What changed in each version.

Last updated 21 October 2026 · Veyndesk 0.5.0

All releases with downloads: GitHub releases.

Next version (unreleased)

  • Settings folder renamed from VeloDesk to Veyndesk; existing settings and IDs are moved automatically on first start.
  • More accurate connection text in the app.

0.5.0 – 21 October 2026

  • macOS app: universal .dmg for Apple Silicon and Intel, Retina-aware mouse positioning, macOS key codes.
  • Linux app: .deb and AppImage (X11).
  • The relay works on all three systems; cloudflared is downloaded automatically for each.

0.4.0 – 21 October 2026

First public release, Windows only.

  • Connect by ID and password; direct P2P connection (WebRTC) with automatic relay fallback.
  • Accept / Deny prompt, permanent password for unattended access, wrong-password lockout.
  • Clipboard sync, multi-monitor, adaptive quality, local network discovery.
  • Windows installer (with firewall rule) and portable zip.
