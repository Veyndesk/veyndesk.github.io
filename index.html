Frequently asked questions

About Veyndesk, the free open-source remote desktop.

Is Veyndesk free?

Yes. Veyndesk is free and open source (AGPL-3.0), for personal and business use. There are no paid plans and no licence key.

Is Veyndesk a good AnyDesk alternative?

Veyndesk works like AnyDesk: you open the app, share your ID and password, and your partner connects. Unlike AnyDesk it is open source and free for commercial use. AnyDesk currently supports more platforms; Veyndesk is Windows-only for now.

Do I need an account or a server?

No. Install Veyndesk on both computers and connect with the ID and password. No account, no server setup and no port forwarding are needed.

Does Veyndesk work on different networks?

Yes. Veyndesk connects the two computers directly (peer-to-peer) and automatically uses a relay when a network blocks direct connections, so it works on home Wi-Fi, office networks and mobile data.

Is it secure?

Connections are end-to-end encrypted, the password is never sent over the network (challenge-response), and the person being connected to must press Accept before anyone can see the screen.

Windows shows a warning when I install it. Why?

Veyndesk is new, and its installer isn't code-signed yet, so Windows doesn't recognise the publisher. Code signing is in progress. You can check the source code on GitHub.
