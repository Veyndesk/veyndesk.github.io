What is Veyndesk?

Veyndesk is free, open-source remote desktop software for Windows, macOS and Linux. Like AnyDesk, each computer shows a 9-digit ID and a password; your partner enters them to see and control your screen. The source code is on GitHub under the AGPL-3.0 licence.

Connect in 3 steps

Install on both computers

Windows, macOS or Linux. Each computer shows a 9-digit ID and a one-time password.

Enter the partner's ID

Type their ID, click Connect, and enter the password they read out to you.

They click Accept

The other person sees who is connecting and chooses Accept or Deny. Full guide with screenshots

What it does today

Features in version 0.5.0, and what's not there yet.

⚡

Direct connection, relay fallback

Connects the two computers directly (WebRTC). If that fails within about 7 seconds, it uses a relay through Cloudflare.

🔑

Password never sent

A challenge–response check proves the password without sending it. 8 wrong attempts in 5 minutes block further tries for a while.

✋

Accept / Deny prompt

One-time-password sessions ask the remote person first. Permanent-password (unattended) sessions don't. Learn more

🖥️

Screen, mouse and keyboard

Adaptive quality, sharper text when the screen is still, multi-monitor, clipboard text sync.

🏠

Works on the local network

Computers on the same network find each other automatically, and you can also connect by IP address.

🔓

Open source

All code is on GitHub. You can run your own server with a web admin panel and audit log.

Known limitations

  • No file transfer, chat, audio or session recording yet. Clipboard text sync works.
  • No mobile apps (Android/iOS) yet.
  • Linux: X11 sessions only. Wayland is not supported yet.
  • macOS: the app is not notarized yet, and it has not yet been tested by the maintainer on a physical Mac (it is built and packaged automatically).
  • Windows: the installer is not code-signed yet, so Windows shows a warning. There is no background service yet, so the login screen and UAC prompts can't be controlled.
  • Internet connections depend on public services (ntfy.sh for finding the partner, Cloudflare for the relay). A network that blocks them can only use Veyndesk on the local network.

Questions and answers

What is Veyndesk?

Veyndesk is free, open-source remote desktop software for Windows, macOS and Linux. Like AnyDesk, each computer shows a 9-digit ID and a password; your partner enters them to see and control your screen. The source code is on GitHub under the AGPL-3.0 licence.

Is Veyndesk free for business use?

Yes. Veyndesk is free for personal and commercial use, with no paid plans or licence keys. The AGPL-3.0 licence only adds obligations if you modify Veyndesk and distribute it or run it as a network service for others; using it unchanged has no such conditions.

Does Veyndesk require a server or an account?

No. You don't need an account, a server or port forwarding. Veyndesk finds your partner through a public message service (ntfy.sh), connects the two computers directly when the network allows, and otherwise uses a relay through Cloudflare that the app sets up itself. You can optionally run your own server. How to connect.

Does every connection need to be accepted?

Not always. With the one-time password, the remote computer shows an Accept / Deny prompt (on by default; it can be turned off in Settings). If you set a permanent password for unattended access, sessions using it start without a prompt. Details.

Is Veyndesk end-to-end encrypted?

Direct (peer-to-peer) connections are end-to-end encrypted with DTLS. Relay connections are encrypted in transit (HTTPS) but pass through Cloudflare's servers, so they are not end-to-end encrypted. Connections made by typing an IP address on a local network are currently not encrypted. The password itself is never sent over the network. Security details.

Does it work on different networks?

It is designed to: it tries a direct connection first and falls back to a relay. Some networks (strict company firewalls, networks that block ntfy.sh or Cloudflare) can still prevent it, and cross-network use has had limited testing so far. Troubleshooting.

Does Veyndesk work on Mac and Linux?

Yes, since version 0.5.0: a universal .dmg for macOS 10.15+ and .deb / AppImage packages for 64-bit Linux (X11 sessions). See Download for requirements and known limitations.

Is Veyndesk on GitHub?

Yes. Veyndesk is developed in the open on GitHub: the source code is at github.com/veyndesk/veyndesk in the Veyndesk organization, and every download is built from it by GitHub Actions and published on the GitHub releases page.

Is Veyndesk the same as Vyndesk or other similarly named products?

No. Veyndesk (spelled V-E-Y-N-D-E-S-K) is an open-source remote desktop app. It is not related to Vyndesk or any other product with a similar name.
